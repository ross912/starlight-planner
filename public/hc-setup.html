三星 S23 手机→ 三星健康→ Health Connect→ 星光手帐
为什么手机就能行？ 你的三星 S23 自带计步传感器，三星健康 App 一直在记录你的步数、距离、卡路里，还能自动识别走路/跑步/骑行。国行三星健康把「健康连接」入口锁了，下面两步就是把它解锁放出来。手表继续戴，不影响。

!先看版本：7.0 新版请先降级

  1. 打开 三星健康 → 设置 → 关于三星健康，看版本号
  2. 6.x（如 6.27 / 6.28） → 直接跳过本步，从下面第 1 步开始
  3. 7.0 及以上（2026 年 6 月后的新版界面） → 三星官方把 Set features 菜单移除了，文件夹法无效，先按下面折叠内容降级再继续
7.0 版本降级到 6.x（社区验证有效）

三星健康 7.0 大改版（2026-06-17 推送）把 Set features 入口移除，盖乐世社区 3 月就有用户反馈，官方至今无解。降级步骤：

  1. 设置 → 应用 → 三星健康 → 右上角 ⋮ → 卸载更新（回退到出厂旧版）；如果它本来就不是系统应用，直接卸载
  2. 手机浏览器打开 APKPure 或 Uptodown，搜 Samsung Health，下载 6.28.x / 6.27.x 版本（约 210MB）安装
  3. 打开三星健康 → 同意隐私协议 → 继续下面第 1 步（文件夹法在 6.x 版本有效）
  4. ⚠️ 解锁成功后：进应用商店把三星健康的自动更新关掉，千万不要升回 7.x，否则入口又没了

0前置确认

  1. 手机已装好 Health Connect（设置 → 应用 → 搜「健康连接」，能看到就说明装好了）
  2. 手机已装好 星光手帐 App（还没装？点这里下载）
  3. 三星健康 App 是最新版（应用商店更新一下）

1开启三星健康开发者模式

  1. 打开三星健康 → 点右下角菜单 → 设置
  2. 拉到最底部 → 关于三星健康 → 连续点击「版本号」约 7 次，直到出现开发者菜单
  3. 点 Developer Mode (Samsung Health Data SDK) → 把 Developer Mode for Data Read 勾选为 ON
  4. 打开手机自带的「我的文件」→ 进入 Download 文件夹 → 新建 SamsungHealth 文件夹 → 在里面再建三个文件夹（大小写必须一致）：
    FeatureManagerOn　FeatureListOn　CscManagerOn
  5. 回到三星健康 → 关于页面，能看到 Set Feature 按钮就成功了
⚠️ 文件夹名严格区分大小写，建错一个 Health Connect 就出不来。
💡 如果手机端「我的文件」建了没反应（7.0 已封的不算）：用数据线连电脑，手机选「传输文件」模式，在电脑的资源管理器里进入 Download 创建同样的文件夹，三星健康只认电脑建的这个。

2把地区改成 US，放出健康连接

  1. 回到「关于三星健康」页面 → 点 Set Feature 进入开发者特性菜单
  2. 点 Common → 把 CSC Country Code 改为 US → 把下方 MCC Configuration 改为 310 (US)
  3. 点 Analytics → 把 [HA] Server 改为 DEV
  4. 点 Data Platform → 把 Developer Mode 和 Data SDK Developer mode 都勾选为 ON
  5. 退出该页面 → 三星健康会要求强制停止 App，照做
  6. 重新打开三星健康 → 重新同意隐私协议
✅ 打开设置，如果出现「健康连接」选项，解锁成功！

3三星健康 → 健康连接 授权

  1. 三星健康 → 设置 → 点 健康连接
  2. 开启「同步到健康连接」→ 在数据授权里把步数、距离、卡路里、运动等全部允许
  3. 打开系统 健康连接 → 权限 → 确认三星健康已授权
💡 手机需要随身携带才会计步（放桌上/充电时不计）。走路/跑步/骑行时让手机在口袋里，数据自动记录。

4星光手帐里收数据

  1. 打开星光手帐 App → 登录账号 → 进入「健身」页
  2. 页面顶部出现手表同步卡片 → 点「授权」→ 允许读取步数/心率/运动等权限
  3. 授权完成自动同步一次 → 卡片显示今日步数 / 千卡 / 距离和最近运动
  4. 之后每次打开 App 或切回前台都会自动同步
🎉 搞定！以后手机计步的数据会一直自动进星光手帐。
常见问题

健身页没有「手表同步卡片」？
确认装的是 starlight-hc 新版 App（从 zixin.space/download.html 下载的）。浏览器里打开网页版不会有这个卡片，必须在 App 里。

授权后还是 0 步？
手机没带在身上/三星健康没开启步数记录。先打开三星健康看看首页有没有步数，有的话等 1-2 分钟再同步一次。

同步报错？
确认系统「健康连接」已授予三星健康和星光手帐读取权限，然后重新打开星光手帐触发自动同步。

这样改有风险吗？
社区大量验证过，可逆。想还原：删掉 Download/SamsungHealth 文件夹，再改回地区代码 CHN 即可。

手表数据为什么不同步？（背景说明）

你的红米 Watch 6 是国行版，固件被区域锁定，国际版 App 连不上（提示"设备不支持"），国行 App 又没有 Health Connect 入口——小米生态的数据出不来。所以改用手机计步 + 三星健康这条免费链路，手表继续戴着看时间、看心率、用表盘，互不影响。
